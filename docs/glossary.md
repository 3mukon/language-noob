Use one canonical name for each concept. The Term column is authoritative for naming and search; Avoid lists alternative names that should not be used.

| Term | Meaning | Avoid |
|---|---|---|
| Word card | A card instance containing one vocabulary entry during a study encounter; studying the same entry again may create a new instance | Browser tab, permanent entry conversation |
| Word page | The explanation and follow-up interface formed by the current word card and its attached lower-right note | Global chat page |
| Follow-up note | A smaller, fixed-size paper attached to the current word card, presenting letter-like messages and progressively displayed replies without a visible panel title; its paper may be tilted, while its text and controls remain upright and its content scrolls independently. This is an internal concept name, not a required UI label | Expandable chat area, independent global chat page |
| Follow-up context | The current study card's word, relevant explanations, and temporary questions and answers; cleared at the end of its lifetime and never persisted | Shared cross-word conversation, permanent entry conversation |
